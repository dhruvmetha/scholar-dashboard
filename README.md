# ScholarDashboard

A research-paper dashboard: weekly digests of new papers built by Claude from Google Scholar alerts and a web survey, ranked by your research interests, with a PDF reader, encrypted notes and highlights (Apple Pencil too), and a chat with Claude Code about the paper you're reading.

Live: https://www.sumanthtangirala.com/scholar-dashboard/

**Want your own?** See [SETUP.md](SETUP.md) for setting it up from scratch: forking, GitHub Pages, digests, notes, and the Claude Code chat.
